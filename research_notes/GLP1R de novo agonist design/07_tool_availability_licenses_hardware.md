## Key Question 1: Per-tool code license, weights license/gating, hardware, determinism (verified from primary sources)

### Takeaway
The generate->sequence->fold->rank stack is dominated by **permissive licenses (MIT / Apache-2.0 / BSD-3 / CC-BY)** that cleanly permit open ODC-BY release of sequences and predicted structures. The only licenses that attach real conditions are **AlphaFold3 weights** (gated, non-commercial, output-notice + no-distillation), **ESM-3 / ESMC-600M** (Cambrian non-commercial + "Built with ESM"), **Protenix-v2 weights** (proprietary), **Profluent-E1** (mandatory attribution), and **PyRosetta** (commercial-use paywall). FoldSeek/MMseqs2 are GPL (software copyleft only; outputs unaffected).

### Inferences
- VRAM: for GLP1R-agonist-scale work (receptor extracellular domain or a truncated construct ~140-460 aa + a <~60 aa peptide/mini-binder), every model fits comfortably on one H100 80GB; co-folders (Boltz-2/Chai-1/Protenix/OpenFold3/AF3) scale ~O(N^2) in total tokens, so only unusually large full-length-receptor complexes would need the kits' `--mode big --n_gpu P` multi-GPU sharding. With 8x H100 the practical strategy is one process per GPU for throughput (consistent with the local GPU policy).
- Determinism: diffusion/hallucination generators (RFdiffusion*, Genie3, BindCraft, BoltzGen) are stochastic but fully seed-reproducible; AF2/co-folders are deterministic given seed+model; the kit `--det` mode gives bitwise reproducibility where byte-level repro of a submitted artifact matters.
- A designed **sequence** is not a copyrightable derivative of model weights under any of these permissive licenses, so MIT/Apache/BSD/CC-BY tools impose no restriction on publishing the designs themselves.

### Gaps
- RFdiffusion-All-Atom (`rf_diffusion_all_atom`) exact LICENSE name not captured (page did not render it); superseded locally by RFdiffusion3 (foundry, BSD-3) so low priority.
- MMseqs2's own LICENSE not independently confirmed this run (GPLv3 strongly indicated via the Foldseek/mmseqs2-server packaging).
- ANARCI and Voronota licenses (BSD-3 and MIT respectively) are from prior knowledge, not re-verified this run; both are peripheral to a GLP1R agonist (antibody numbering not needed).
- Exact per-model peak VRAM figures were not drawn from primary benchmarks (stated as engineering estimates).

## Key Question 3: Output-release (ODC-BY) license blockers for public release of sequences + structures + methods

### Takeaway
For the fully-open deliverable, **avoid AlphaFold3 official weights and Protenix-v2 weights entirely**, and either avoid or carefully attribute **ESM-3/ESMC-600M** and **Profluent-E1**. Everything else (RFdiffusion*/BSD, ProteinMPNN/LigandMPNN/BindCraft/MIT, Chai-1/Caliby/Genie3/PXDesign/Protenix-v1/Apache, AF2 params/CC-BY, Boltz-2/BoltzGen/MIT) is clean for ODC-BY output release. PyRosetta is clean for publishing outputs but raises a commercial-status question for the challenge.

### Cited Findings
- **AlphaFold3 (official DeepMind weights) — the main blocker.** Params are non-commercial, request-gated, and non-redistributable; outputs are publishable **only** with a conspicuous "subject to AF3 Output Terms of Use" notice and are barred from training competing predictors — [AF3 OUTPUT_TERMS_OF_USE.md](https://github.com/google-deepmind/alphafold3/blob/main/OUTPUT_TERMS_OF_USE.md); [AF3 WEIGHTS_TERMS_OF_USE.md](https://github.com/google-deepmind/alphafold3/blob/main/WEIGHTS_TERMS_OF_USE.md). This adds conditions on top of a pure ODC-BY release and carries a non-commercial field-of-use restriction (Adaptyv/Anthropic are commercial entities). Mitigation: use OpenFold3 (Apache-2.0, of3-p2 checkpoint, already wired via the `af3_jax` kit), Boltz-2, Chai-1, or Protenix-v1 — none impose output conditions.
- **Protenix-v2 weights are proprietary/confidential and not open-source** — [bytedance/Protenix](https://github.com/bytedance/Protenix). Outputs from them could carry restrictions; also unavailable (403). Use Protenix v0.5.0/v1 or PXDesign Apache weights.
- **ESM-3 and ESMC-600M (Cambrian Non-Commercial)**: non-commercial use only, cannot offer outputs as a service, mandatory "Built with ESM" attribution — [Cambrian Non-Commercial License](https://www.evolutionaryscale.ai/policies/cambrian-non-commercial-license-agreement). Publishing sequences/scores is not "offering a service," so open release is permissible, but the non-commercial limitation and attribution attach. Mitigation: use ESM-2 (MIT) and/or ESMC-300M (Cambrian Open) for naturalness/ranking to keep outputs cleanly open.
- **Profluent-E1**: clickthrough license requiring "Profluent-E1" attribution in distributions/documentation (and a runtime display for object-form redistribution) — [local NOTICE](/home/prachh/v/anthropic-adaptyv-2026-tnf/third_party/uplifting-biomolecular-modeling/NOTICE). Not a blocker for publishing sequences, but the attribution must appear in the methods.
- **PyRosetta commercial paywall**: free for academic/non-profit; commercial use needs a paid UW license — [pyrosetta.org licensing](https://www.pyrosetta.org/home/licensing-pyrosetta). The license governs software use, not sequence IP, so publishing PyRosetta-derived scores/designs under ODC-BY is fine; the open question is whether the Anthropic x Adaptyv challenge counts as "commercial."
- **FoldSeek (GPL-3.0) / MMseqs2 (GPLv3)**: copyleft binds redistribution of the *software*, not the *outputs* (novelty TM-scores/hits), so no conflict with publishing results — [steineggerlab/foldseek](https://github.com/steineggerlab/foldseek).
- **NVIDIA Open Model License (Proteina/Complexa weights)**: permits commercial use and NVIDIA claims no ownership of outputs, with attribution/compliance conditions — [local complexa/STOCK.md](/home/prachh/v/anthropic-adaptyv-2026-tnf/third_party/uplifting-biomolecular-modeling/complexa/STOCK.md). Acceptable for ODC-BY output; note the license in methods.
- **AF2 parameters (CC BY 4.0)** used by BindCraft/ColabDesign/af2ig require only attribution — [google-deepmind/alphafold](https://github.com/google-deepmind/alphafold).

### Inferences
- A pipeline built from {RFdiffusion/RFpeptides/RFdiffusion3 (BSD-3), BindCraft+ColabDesign (MIT/Beerware + AF2 CC-BY), BoltzGen (MIT), Genie3 (Apache), PXDesign/Protenix-v1 (Apache)} -> {ProteinMPNN/LigandMPNN (MIT), Caliby (Apache)} -> {af2ig (MIT+CC-BY), Boltz-2 (MIT), Chai-1 (Apache), OpenFold3 (Apache)} -> {ESM-2 (MIT)/ESMC-300M (Cambrian Open), FoldSeek novelty} produces designs with **zero license conflict** against open ODC-BY release, needing only standard attributions (AF2 CC-BY, Genie/PXDesign/Chai Apache NOTICE).
- Because the challenge explicitly allows "any method" and publishes outputs openly, the cleanest defensive posture is to keep AF3-official, ESM-3/ESMC-600M, and Protenix-v2 out of the submitted-design provenance chain, so no output-notice or non-commercial clause can be argued to ride along with the published sequences/structures.

### Gaps
- The challenge's own rules may themselves specify permitted tools or required attributions for ODC-BY submissions; that governance text was not in scope here and should be checked against these tool terms.
- Whether Anthropic x Adaptyv treat the challenge as "commercial" for PyRosetta/ESM-NC purposes is a policy question, not resolvable from licenses alone.
